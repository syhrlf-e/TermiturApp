# Termitur v2.0.0 (Tauri Edition)

> **Your terminal, now structured.**

Termitur is a desktop terminal manager designed for developer enthusiasts who frequently work with multiple projects. It brings project-based terminal management with a sidebar for project navigation, independent terminal tabs, git detection, and persistent session state.

Built with Tauri v2 (Rust backend + React 18 frontend).

## Development Setup

1. Install prerequisites (Node.js, Rust, Tauri dependencies).
2. Install frontend dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run tauri dev
   ```
